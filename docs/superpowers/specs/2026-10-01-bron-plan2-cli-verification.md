## Command templates that worked

Run all from the vault root (cwd = vault; paths with spaces must be quoted).

Claude, run as agent:
```
claude -p "<prompt>" --agent <agent-key> --output-format json [--settings <perm.json>] [--disallowedTools mcp__claude_ai_<Name> ...]
```
Read `session_id`, `result`, `is_error`, `permission_denials` from stdout JSON. Optional `--model <alias>` was not tested.

Claude, resume:
```
claude -p --resume <session_id> "<prompt>" --agent <agent-key> --output-format json [--settings <perm.json>]
```
(`--agent` optional; the session keeps its agent. `--settings` on resume was not re-tested: pass it again to be safe, UNVERIFIED that it is not remembered.)

Codex, run as agent:
```
codex exec --json --skip-git-repo-check --dangerously-bypass-hook-trust \
  -c 'developer_instructions="<agent instructions as a TOML string>"' \
  [-m <model>] [-c 'mcp_servers.<id>.enabled=false'] [-c 'mcp_servers.<id>.disabled_tools=["x"]'] "<prompt>" 2>stderr.txt
```
Read `thread_id` from the first JSONL line (`thread.started`); the final text is the last `item.completed` with `item.type == "agent_message"`. Prompt is read from the argument; stdin note: `Reading additional input from stdin...` appears on stderr. `--model` override, `-m`, accepted; the model name tested was `gpt-5.5` on resume only.

Codex, resume:
```
codex exec resume --json --skip-git-repo-check --dangerously-bypass-hook-trust <thread_id> "<prompt>" 2>stderr.txt
```
Instructions persist in the thread; add `-c` / `-m` only to change something.
